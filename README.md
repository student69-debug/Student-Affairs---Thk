# Student Affairs – Thk

ระบบงานกลุ่มบริหารกิจการนักเรียน โรงเรียนธรรมศาสตร์คลองหลวงวิทยาคม

- เว็บ: https://student69-debug.github.io/Student-Affairs---Thk/ (GitHub Pages)
- ฐานข้อมูล: Supabase (โปรเจกต์ `student-affairs-thk`) — สิทธิ์การเข้าถึงคุมด้วย Row Level Security
- หน้าเว็บ: HTML/CSS/JavaScript ล้วน ไม่ต้อง build

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า (sidebar, topbar, หน้าเข้าสู่ระบบ) |
| `css/styles.css` | สีและรูปแบบตาม design system Student Affairs – Thk |
| `js/config.js` | URL + publishable key ของ Supabase (เปิดเผยได้) |
| `js/store.js` | อ่าน/เขียนฐานข้อมูล |
| `js/ui.js` | ตัวช่วยแสดงผล วันที่ไทย dialog toast |
| `js/apps.js` | แอปย่อย: ดูแลช่วยเหลือ (รวมบันทึกสุขภาพ) · พฤติกรรม/ตัดคะแนน |
| `js/counsel.js` | ระบบเคสให้คำปรึกษา (ย้ายจากระบบเดิมบน Apps Script): ประเภทปัญหา K1–K11 ความรุนแรง แผน ผู้รับผิดชอบ ขั้นตอนก่อนเริ่ม บันทึก 6 ครั้ง นำเข้า/ส่งออก |
| `js/pages.js` | หน้าแรก ค้นหา นักเรียนรายคน ทะเบียน รายงาน ตั้งค่า |
| `js/main.js` | router, การเข้าสู่ระบบ (บุคลากร / ผู้ปกครอง), ปุ่มต่าง ๆ |
| `js/apikeys.js` | ตั้งค่า → การเชื่อมต่อ API: ออก/ยกเลิกกุญแจให้ระบบอื่น และดูประวัติการเรียกใช้ |
| `js/parent.js` | หน้าสำหรับผู้ปกครอง (ข้อมูลจาก `parent_view()` ที่กรองตามการตั้งค่า) |
| `supabase/functions/parent-activate` | Edge Function เปิดใช้งานบัญชีผู้ปกครองด้วยรหัสนักเรียน + เลขประจำตัวประชาชน (จำกัดการลองผิด) |
| `js/seed.js` | ข้อมูลตัวอย่าง (ชื่อสมมติ) สำหรับทดลอง |

## สิทธิ์ผู้ใช้

- **ผู้ดูแลระบบ** — ทุกอย่าง รวมทะเบียนนักเรียนและการอนุมัติผู้ใช้
- **ครูแนะแนว** — นักเรียนทุกคน รวมเนื้อหาการให้คำปรึกษาระดับลับ
- **หัวหน้า / รองหัวหน้าระดับ** — รายละเอียดนักเรียนในระดับชั้นที่ดูแล
- **ครูที่ปรึกษา / ครูทั่วไป** — รายละเอียดนักเรียนในห้องที่ปรึกษา
- **ครูประจำวิชา** — เห็นพฤติกรรมของนักเรียนห้องที่สอน (นำเข้าที่ ตั้งค่า → ครูประจำวิชา จับคู่ด้วยอีเมล)
- เคสให้คำปรึกษา: เนื้อหาเต็มเฉพาะครูแนะแนว/ผู้ดูแลระบบ · ครูที่ปรึกษา/หัวหน้าระดับเห็นแค่ความคืบหน้า (`case_progress()`)
- ทุกบทบาทค้นหาและบันทึกพฤติกรรมนักเรียนได้ทุกคน
- **แอปที่ใช้ได้รายคน** — ผู้ดูแลระบบปิดแอปให้แต่ละคนได้ที่ ตั้งค่า → ผู้ใช้และสิทธิ์ (`profiles.app_access`, บังคับในฐานข้อมูลด้วย `private.app_ok()`)
- **ผู้ปกครอง** — เข้าที่ `#/parent` เห็นเฉพาะลูกของตัวเอง ตามที่ตั้งไว้ใน ตั้งค่า → ผู้ปกครอง (ไม่เห็นการให้คำปรึกษาระดับลับ การส่งต่อ ข้อมูลสุขภาพ)

รูปนักเรียนเก็บใน Supabase Storage (bucket `student-photos` แบบส่วนตัว) ชื่อไฟล์ `<รหัสนักเรียน>.jpg`
